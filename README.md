# FinGraph – Real-Time Fraud Syndicate Analytics

## 📌 Overview
FinGraph is a solo project under Infotact’s Advanced Data Analytics program.  
It focuses on **real-time fraud detection** using streaming graph analytics.  
The goal is to detect complex money laundering syndicates that evade traditional rule-based systems.

---

## ⚙️ Tech Stack
- Python → Transaction simulator  
- Apache Kafka → Streaming ingestion  
- Apache Flink → Real-time stream processing  
- Neo4j → Graph database + Cypher queries  
- Neo4j GDS → Graph algorithms (PageRank, Louvain)  
- React / Linkurious → Interactive fraud detection dashboard
